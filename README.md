# Memorial de Víctimas del Conflicto Armado en Caldas

## Descripción del Proyecto

El **Memorial de Víctimas del Conflicto Armado en Caldas** es una
plataforma web interactiva diseñada para visibilizar, preservar y
difundir la memoria histórica de las víctimas del conflicto armado en el
departamento de Caldas, Colombia.

El proyecto busca contribuir a la construcción de memoria colectiva
mediante el uso de tecnologías web modernas que permitan explorar
historias, datos y testimonios de manera accesible y educativa.

------------------------------------------------------------------------

## Objetivos

-   Preservar la memoria histórica de las víctimas del conflicto armado.
-   Facilitar el acceso público a información relevante y documentada.
-   Promover la reflexión, la educación y la conciencia histórica.
-   Proporcionar una plataforma digital accesible e interactiva.

------------------------------------------------------------------------

## Características Principales

-   Visualización interactiva de información histórica.
-   Navegación intuitiva por secciones temáticas.
-   Arquitectura moderna basada en componentes.

## Instalación y Ejecución

Para ejecutar el proyecto en un entorno local:

### 1. Clonar el repositorio

    git clone https://github.com/andres930500/memorial-victimas-caldas.git

### 2. Ingresar al proyecto

    cd memorial-victimas-caldas

### 3. Instalar dependencias

    npm install

### 4. Ejecutar el servidor de desarrollo

    npm run dev

La aplicación estará disponible normalmente en:

    http://localhost:5173

## Flujo de Desarrollo

Se recomienda trabajar utilizando ramas para mantener una estructura
ordenada:

-   `main` → versión estable
-   `develop` → integración de desarrollo
-   `feature/*` → nuevas funcionalidades

Ejemplo:

    git checkout -b feature/nueva-funcionalidad
